# Artes para Universos Visuais

Envie aqui as imagens que servirão de base para novos temas do Bizuteca 9MM.

1. Nesta pasta, clique em **Add file → Upload files**.
2. Envie as imagens separadamente em PNG, JPG ou WebP. Pode manter os nomes originais.
3. Clique em **Commit changes** para concluir.

Cada arte pode virar um tema com nome inspirado na cena. A adaptação inclui recorte, enquadramento e transições suaves para integrar a imagem à Home e ao editor.

O repositório é público. Envie imagens que você possa disponibilizar publicamente. Os arquivos desta pasta são referências para a adaptação e só entram no aplicativo depois de preparados.
