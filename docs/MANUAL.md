# Manual do Bizuteca 9MM

**Anote. Organize. Revise. Domine.**

## Começar

Baixe o executável Windows de 64 bits na página de versões do repositório e abra **BIZUTECA-9MM-Portatil.exe**. A abertura fecha sozinha quando o caderno está pronto.

Uma biblioteca nova começa vazia. Clique em **Pasta**, escreva um nome e selecione um destino. **Nível principal** cria uma matéria. Pesquise pelo nome ou pelo caminho para criar uma subpasta. Em **Dados e configurações**, use **Acrescentar modelo TEC** se quiser a estrutura pronta.

Arraste a borda da biblioteca para ajustar a largura. Clique duas vezes na borda para retornar ao padrão. Os trechos do caminho acima da nota abrem as respectivas pastas. Use **Voltar** e **Avançar**, ou **Alt + ←** e **Alt + →**.

## Escrever e localizar material

Abra **Nova anotação** e escreva no editor. A barra principal formata texto, insere imagens, tabelas e blocos de Bizu ou Pegadinha. **Mais ferramentas** reúne alinhamentos, links, listas de verificação, símbolos, modelos e edição de linhas e colunas. Selecione uma célula para editar uma tabela sem mesclagens. Use **Ctrl + Shift + V** para colar sem formatação.

Clique com o botão direito em uma imagem para copiá-la, salvá-la ou ajustar a largura. O redimensionamento afeta sua aparência dentro da nota. As imagens originais continuam disponíveis para salvar. Use **Versões** para recuperar uma edição anterior.

O indicador inferior informa se a gravação foi confirmada. **Ctrl + S** salva imediatamente. Use a busca no topo e escolha toda a biblioteca, a matéria ou a pasta. Dentro de uma nota, **Ctrl + F** leva ao campo de busca. **Sumário** lista os títulos da anotação.

## Calendário

Abra **Calendário** no menu lateral. Escolha uma data e clique em **Novo evento**. Informe o título, a data e, se quiser, o horário e uma observação. Use **Editar** para alterar ou excluir.

A Home mostra o próximo compromisso. Clique nele para abrir o dia correspondente. Eventos sem horário de hoje aparecem durante todo o dia.

## Guardar, importar e restaurar

- **Backup** cria uma cópia completa, incluindo imagens, temas e eventos. **Dados e configurações** permite escolher outra unidade para uma cópia adicional.
- **Exportar biblioteca completa** gera um pacote **.b9mm** no local escolhido.
- **Acrescentar materiais** inclui notas e eventos na biblioteca atual. Notas idênticas no mesmo caminho e eventos com os mesmos campos são ignorados.
- **Restaurar biblioteca** valida o pacote, faz um backup da biblioteca atual e ativa uma biblioteca restaurada em uma pasta separada. Para voltar, use **Abrir outra biblioteca** e escolha a pasta anterior.
- Os pacotes antigos **.bizuteca** e **.tvbackup** continuam disponíveis nos filtros de importação.
- No editor, **Exportar** cria um arquivo em PDF, HTML ou TXT da nota aberta.

## Atualizar sem perder anotações

1. Na versão anterior, use **Backup** e guarde a cópia em um local que você consiga encontrar.
2. Feche o programa.
3. Na mesma pasta, substitua o executável pelo novo. Preserve a pasta **BIZUTECA-Suporte** e a pasta de dados escolhida.
4. Abra a nova versão e confira seus materiais. **Local de salvamento → Abrir pasta** mostra o endereço da biblioteca ativa.
