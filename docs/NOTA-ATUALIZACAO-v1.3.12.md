# Bizuteca 9MM 1.3.12

Pesquisa ampliada e editor com menos ferramentas expostas, preservando a identidade visual e o formato .b9mm.

## Pesquisa

- Flexões em português, siglas nos dois sentidos e números por extenso.
- Números de leis com ou sem separador: 14.133 e 14133.
- Frases entre aspas continuam obrigatórias.
- Consulta automática por tema ou enunciado, com seletor para escolher manualmente.
- Siglas pessoais em Dados e configurações. O dicionário acompanha a biblioteca, inclusive ao exportar e restaurar .b9mm, sem alteração do formato do pacote.
- O índice é reconstruído na migração e na importação; notas, versões e anexos são preservados.

## Editor

Uma barra principal. Formatação adicional no botão “…”. Modo Foco, leitura, sumário, etiquetas, anexos, versões e exportação ficam nas opções da anotação.

| Atalho | Ação |
|---|---|
| Ctrl B / I / U | Negrito, itálico, sublinhado |
| Ctrl K no corpo | Inserir ou editar link |
| Ctrl Alt 1 / 2 / 0 | Título, subtítulo, texto |
| Ctrl Shift 7 / 8 / 9 | Lista numerada, marcadores, tarefas |
| Ctrl Shift B / P | Bizu / Pegadinha |
| Ctrl Shift H / X | Último marca-texto / tachado |
| Ctrl Shift V | Colar texto puro |
| Ctrl F | Buscar nesta anotação |
| Tab / Shift Tab em tabela | Próxima / célula anterior |
| Tab / Shift Tab em lista | Aumentar / diminuir recuo |
| Ctrl Enter em bloco | Sair do bloco; em tarefa, alternar conclusão |
| Esc | Sair do foco, fechar busca e menus |

No início da linha: "# " cria título; "## " subtítulo; "- " ou "* " marcadores; "1. " lista numerada; "> " citação; "[] " tarefa; "---" seguido de Enter cria separador. Digite "/" para escolher um bloco.

Colar normalmente limpa fontes, tamanhos e cores externas. “Colar mantendo formatação” está no menu de formatação. Imagens do clipboard e imagens embutidas são armazenadas como anexos. Notas têm limite de 5 MB de HTML; imagens, 20 MB.

O corretor usa pt-BR quando o dicionário do sistema está disponível. A instalação do dicionário pode depender de conexão com a internet. A consulta ao caderno continua offline.
